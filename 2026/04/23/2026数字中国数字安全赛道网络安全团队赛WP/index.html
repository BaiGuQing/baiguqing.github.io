KSA（密钥调度）

两个关键改动：

  2. PRGA 中 k = (S[i] + S[j]) ^ pos（用输出位置 XOR 替代 S-box 索引）

0x07 总结

本题是一个典型的 CTF 逆向题，考察点包括：

  1. Core dump 分析 — 识别 core dump 文件并加载到 IDA 分析

  2. XOR 加密数据识别 — 通过 init 函数发现静态数据在编译时被 XOR 加密

  3. 魔改 RC4 识别 — 对比标准 RC4 发现 KSA 多了 +i 和 PRGA 的 ^pos 改动

  4. 自定义 Base64 — 位置相关的偏移量 (pos % 7) + 3 + 乱序字母表
