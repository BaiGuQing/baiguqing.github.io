Win32 API

  • 主要存放在C:\\WINDWOS\system32下面所有的dll
  • 重要DLL：
    • Kernel32.dll：最核心的功能模块，比如管理内存、进程和线程相关的函数等
    • User32.dll：是Winodws用户界面相关应用程序接口，如创建窗口和发送消息等
    • GDI32.dll：全称是Graphical Device Interface（图形设备接口），包含用于画图和显示文本的函数
