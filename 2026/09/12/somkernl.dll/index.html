somkernl.dll

2026-9-12 实战 #样本分析

来源

  • 伪装成 360 的病毒_360社区

在线沙盒

  • 样本报告-微步在线云沙箱 (threatbook.com)

分析函数

DLLEntryPoint

  • 流程简单，先检测环境后隐藏窗口，开始构建并运行
  • 检测失败就重启

CheckEnvironment

CheckEXE

  • 核对一下input的exe名和当前运行的是否是一个exe

HideWindows

  • 有的注释了就不用重复讲了，里面就是CheckEXE单个函数
  • SetWindowLongW(hWnd, nIndex: -20, dwNewLong: WindowLongW & 0xFFFBFF7F | 0x80);
  • 把窗口设置为工具窗口，同时移除 WS_EX_APPWINDOW，让窗口不出现在任务栏。
  • 实际上就是隐藏了exe的窗口

MainFunction

  • 我对sub_1001A491函数的部分内容简单重命名并注释了一下
  • 深度分析后发现这个就是一个RAT远控程序
  • 有着这么多功能

sub_10015B32

  • 种子 → 钳位出密钥对 → 签名 PRO_RAM_AGENT_HELLO_V1 身份串并哈希 → 生成 agent_id / 公钥 / 身份指纹 / 主机指纹 / 签名，装入 384B 结构。（sub_10015964），存在identity.bin
  • 它既是启动时互斥体名（Global\ProRAM-Agent-<摘要> 取的就是这里的哈希）的来源，也是每次 C2 握手证明”同一台被控机”的核心材料。

RestartEXE

  • 就是设置下环境并重启

总结

  • 典型的”白加黑”DLL 侧加载木马
  • 360speedld.exe为正常程序
  • somkernl.dll 名称冒用正版 360 组件，实际为自研 C2 agent
  • 执行流程
  • C2
    • 主通道：wss://clash-verge-upgrade.com/edge-af6032129bd933a9/agents/stream
    • 备用通道：dns://d.clash-verge-upgrade.com/poram?http=https://clash-verge-upgrade.com（DNS 隧道）
  • 协议
    • WebSocket RFC6455 + MsgPack

清除建议

  1. 整包按木马处置；360speedld.exe 本身干净（360 正版），但同目录 DLL 必须删除，勿单独放行该目录
  2. 检查并清理上述注册表 Run 项与 %ProgramData%\ProRAM、%LOCALAPPDATA% 下的 identity/状态文件
  3. 封锁两个 C2 域名的 DNS/出网；WSS 443 + DNS 53 需一起查
  4. 若机器曾运行：排查进程树中无窗口的 360speedld.exe、异常 LoadLibrary 注入行为及 fixmbr.exe 落地
